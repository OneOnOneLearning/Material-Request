# Material Request Form

An online form for tutors to request learning materials for their students.

## What This Form Does

Tutors use this form to:
- Enter their information and select their Program Coordinator
- Add up to 4 students per request
- Choose Math and/or ELA materials for each student
- Select specific learning standards by grade level
- Add notes or special requests

When a tutor submits the form, the request is automatically sent to the curriculum team's SharePoint list for review and fulfillment.

## How It Works

1. **Tutor fills out the form** on the website
2. **Form submits to SharePoint** via Power Automate
3. **Curriculum team reviews** requests in SharePoint/PowerApps
4. **Materials are prepared** and sent to the tutor

## Key Features

- Easy-to-use interface
- Mobile friendly
- State-specific curriculum standards
- Supports multiple students per request
- Automatic submission tracking with Request IDs

## Configuration Files

| File | Purpose |
|------|---------|
| `index/programcoordinators.js` | List of Program Coordinators (names and emails) |
| `index/standards.js` | Learning standards organized by state and grade |

To update coordinators or standards, edit these files directly.
